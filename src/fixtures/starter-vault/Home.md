# Welcome to your notes

This folder is your LifeOS notebook: plain `.md` files that any text editor opens. LifeOS reads
them and writes only small, single-line changes (a ticked box, a new task, a log line), so you can
keep editing them yourself at the same time. Obsidian is optional and nice for browsing them.

## The folders

- **Daily Notes/** one note per day, named like `2026-10-20.md`: a Plan, Tasks and Notes. LifeOS
  makes today's note when it first needs it.
- **Weekly Notes/** one note per week (`2026-W43.md`) with that week's events under each day.
- **Areas/Habits/** one note per habit, with a log of each day (`clean`, `slip` or `skip`).
- **Areas/Goals/** one note per goal; tasks anywhere that carry `@its-name` count toward it.
- **Areas/Lists/** `shopping.md` and `wishlist.md`.
- **Resources/** things to keep: `links.md`, and the hadith library LifeOS shows a reminder from.
- **Inbox/** new notes from LifeOS land here.
- **Archive/** what you archive in LifeOS moves here, so nothing is ever thrown away.
- **Templates/** `Daily Note.md` is the shape of a new daily note; change it as you like.

## Writing tasks by hand

A task is a line like `- [ ] Call the dentist 📅 2026-10-23 ⏰ 09:00`:

- `📅 2026-10-23` the day it is due, `⏰ 09:00` a reminder (or `⏰ maghrib+30`, after a prayer)
- `🔁 every week` repeats it, `⏫` makes it high priority
- `@goal-name` links it to a goal, `#tag` tags it

You can delete this note whenever you like.
